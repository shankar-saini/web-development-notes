## 🗺️ Topics Covered & Quick Links

Aap niche diye gaye links par click karke seedhe specific notes par jaa sakte hain:

### 🏗️ 1. [HTML Notes](./HTML-Notes.md)
* **Beginner:** HTML Structure, Tags, Elements, Attributes, Links, Lists, aur Tables.
* **Intermediate:** Forms, Input Types, Form Validation, aur Semantic HTML (Header, Nav, Section).
* **Advanced:** Meta Tags, Responsive Viewport, SEO Basics, Accessibility (ARIA Basics), aur Best Practices.

### 🎨 2. [CSS Notes](./CSS-Notes.md)
* **Beginner:** Selectors, Box Model (Margin, Padding, Border), Specificity, Units (px, rem, em), aur Colors.
* **Intermediate:** Layouts (Display, Position), Flexbox (Main & Cross Axis), aur Grid Layouts (2D).
* **Advanced:** Responsive Design (Media Queries), clamp()/calc() Functions, Transitions, Transforms, Animations, aur CSS Variables.

### ⚡ 3. [JavaScript Notes](./JAVASCRIPT-Notes.md)
* **Fundamentals:** Variables (var, let, const), Data Types, Strict Operators (== vs ===), aur Control Flow.
* **Core Concepts:** Functions (Arrow & Callbacks), Array Methods (map, filter, reduce), aur Objects (Destructuring & Spread).
* **Advanced JS:** Scope, Hoisting, Closures, `this` keyword, call/apply/bind, Event Loop, Classes, aur ES6 Modules.
